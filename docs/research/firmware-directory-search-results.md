2. **Build artifacts:** `firmware/build/` is the sole build output directory (199MB), containing all flashable binaries.

3. **No scattered firmware:** Unlike some projects that separate components across multiple directories, Spaxel consolidates everything under `firmware/`.

4. **Runtime vs. firmware distinction:** The `data/` directory contains runtime data files (`.bin` extension) that are NOT firmware - these are CSI replay buffers and installation secrets.

5. **Empty OTA storage:** `data/firmware/` exists but is empty, likely reserved for OTA firmware storage during runtime.

1. **Firmware development:** All firmware work should happen in `firmware/main/` for source code and `firmware/build/` for build artifacts.

2. **Clean builds:** `firmware/build/` can be safely deleted to clean build artifacts (regenerated by `idf.py build`).
